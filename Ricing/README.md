# 🎨 Kali Ricing

### 🖼 Обои (Wallpapers) 
Основной источник качественного бэкграунда для рабочего стола:
* **[Wallhaven](https://wallhaven.cc/)** — топовая площадка для поиска обоев в высоком разрешении под любые сетапы.

### 📁 Иконки (Icons)
* **/icons/** — локальная папка репозитория со всеми необходимыми кастомными иконками.

### 🔖 Закладки (Browser)
* **`bookmarks.html`** — файл для импорта закладок. Содержит структурированную базу полезных ресурсов.
