### Where and How to Contribute to Kali  
**Kali Linux** - это большой проект, состоящий из множества различных частей. Один из самых популярных вопросов, который получает команда Кали: «Как я могу помочь?» Чтобы ответить на этот вопрос, эта страница будет содержать все возможные способы, которые члены сообщества могут внести свой вклад.
